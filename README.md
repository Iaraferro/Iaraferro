### Sobre mim

Graduanda em Sistemas de Informação pela UNITINS, com experiência em suporte de TI e desenvolvimento de sistemas.

Tenho direcionado meus estudos ao desenvolvimento back-end, trabalhando com Java, Quarkus, C# e .NET na construção de APIs REST e na integração com bancos de dados relacionais.

Nos meus projetos, busco aplicar boas práticas de programação, organização em camadas, autenticação e integração entre serviços, aprimorando continuamente meus conhecimentos em desenvolvimento de software.
